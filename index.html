Slide syntax

Separate slides with a line containing only ---. The first line of each block is the type in brackets. Use **double asterisks** for bold orange text.

  • [cover] title, accent, sub (title/accent can repeat for more lines)
  • [tip] number, headline, bullets (lines starting with - )
  • [rank] number, name, rating (0–5, halves ok), reason
  • [tier] letter (S A B C D F), verdict
  • [reference] headline, number, breakdown, labels (1–4 lines)
  • [cta] headline, body, action (text in "quotes" becomes the orange keyword)
  • [explainer] label, headline, body, corner (left/right, optional)
